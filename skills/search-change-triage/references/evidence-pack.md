## 3. 14-day evidence pack

- GSC: Web vs Images vs Video vs News vs Discover vs **Generative AI** impressions (Search report worldwide as of 31 Aug 2026; may still be empty without enough gen impressions). Confirm Settings → Search generative AI = Include unless opted out on purpose. Treat gen-AI position as a **feature block**, not per-citation rank inside AIO/AI Mode. When reading Performance, note the **multimodal** search-type filter (Lens / Circle to Search / image upload / Chrome image search; blog 24 Sep 2026) — measurement only, not a ranking lever
- Rank tracker overlap with the update window. For a multi-phase spam rollout, mark each reported impact day (not just the start date) before attributing a drop. If tracker drops are not mirrored in GSC impressions/clicks, suspect tracker data quality before ranking loss (trade-reported tracker noise from 26 Sep 2026)
- **GSC freshness first.** Performance data can lag more than the usual 1–2 days (trade-reported >64 h delay on 11 Oct 2026; [SER](https://www.seroundtable.com/google-search-console-performance-report-delayed-42271.html)). Check the report's **Last updated** stamp and drop incomplete right-edge days before reading any cliff
- **Preferred Sources selection counts** may arrive as a Google **email** to site owners (not a GSC report; first sent ~6 Oct 2026). Record it as measurement only — not a ranking signal and not a traffic KPI
- Performance now supports **multi-select countries / devices** (Search Central LinkedIn, 6 Oct 2026; compare is still two-at-a-time). Use it to build one geo segment instead of stitching exports — measurement only
- Bing AI Performance (Intents / Topics / Citation Share / Compare when available) + Clarity citations if Copilot matters
- Same 10–20 prompt grid on ChatGPT / Perplexity / AIO (same wording, same geo)
- Server / robots / sitemap / analytics integrity. AI referrals: Gemini links began carrying UTM parameters around 1 Oct 2026 (observed, undocumented) — segment them before calling AI traffic flat or up
- If the property has a content-change log: require a **blog-wide / sitewide control window** (same dates, all pages) before blaming a core or spam update on a title rewrite. A +28 / +56 day re-read of the edited URL plus the sitewide line is the default. Reference ranges for "still processing vs stuck" are in the technical-seo-2026-delta checklist §5 (`../technical-seo-2026-delta/references/checklist.md`) (attendee recap, not SLAs)
- If the ask is vertical aggregator / supplier / CSS / jobs / places in EEA, Türkiye, or South Africa: check [regional SERP units](https://developers.google.com/search/docs/appearance/aggregator-features) eligibility before inventing a ranking fix
